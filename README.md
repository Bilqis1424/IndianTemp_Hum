## Data Source and Provenance (Reviewer Comment 9)

The dataset is the **Indian Weather Repository**, publicly available on Kaggle. The raw file used for every result in this repository is `IndianWeatherRepository_raw.xlsx`: 34,466 observations across 543 locations, sampled at ~6-hour intervals from 2023-08-29 to 2023-10-30.

### Provenance of the exact file used in the final reported run

* **SHA-256 hash:** `5811ab9d3584e8a83d86c91fe2b9b7004b3a8feb5054c9e605050a83c1ac6792`
* **Recorded date:** `2026-08-16`

> **Note on the date field:** This date is the file's last-modified timestamp at the time of this run, used as a proxy in the absence of a separately recorded acquisition date — it is *not* necessarily the date the file was first downloaded from Kaggle. If you have the true original download date on record (e.g., from your own download history), replace the date above with that value and note the substitution here. The SHA-256 hash, by contrast, is a genuine, verifiable fingerprint of the exact file bytes and will reproduce identically for anyone hashing the same file.

To independently verify you are working with the identical file, run:


sha256sum "csv files/IndianWeatherRepository_raw.xlsx"

and confirm the output matches the hash above. The pipeline also recomputes and logs this hash automatically at the start of every run (see `get_dataset_provenance()` in `indianweather files/indian_weather_pipeline_v3_final.py`), so any future re-run against a modified or re-exported copy of the source file will produce a different hash and should be treated as a different dataset snapshot.

## Execution instructions (Reviewer Comment 8)

The full pipeline is compute-intensive — per-city ARIMA order search and true leave-one-city-out evaluation across all 543 locations together take on the order of 20–30 minutes on a standard CPU.

### Full run, single command

```bash
python "indianweather files/indian_weather_pipeline_v3_final.py"

```

Runs every stage in sequence (data validation → feature engineering → persistence/ARIMA/LSTM baselines → stacked ensemble → walk-forward validation → full 543-city LOCO → SHAP → residuals → multi-step forecasting → study-city figures) and writes outputs to `csv files/`, `visualisations/`, and `model_artifacts/`.

### Quick smoke test

For a fast verification (fewer ARIMA/LOCO cities, fewer LSTM epochs — minutes instead of tens of minutes), set `fast_smoke_test=True` inside the `main()` call at the bottom of `indianweather files/indian_weather_pipeline_v3_final.py`:

```python
if __name__ == "__main__":
    main(fast_smoke_test=True)

```

This is intended to confirm the pipeline runs end-to-end without error before committing to a full reported run — the resulting numbers will differ from the results below and should not be cited as reported results. Set it back to `False` (the default) to reproduce the numbers in `Methodology_Report.docx`.

## 📊 Results Summary

Full per-fold, per-city, and per-horizon tables underlying every number below are written as CSV files to `csv files/` by `indianweather files/indian_weather_pipeline_v3_final.py` (walk-forward results, per-city ARIMA order/AIC/accuracy, per-location LOCO results, and multi-step MAE/RMSE/R² by horizon), alongside every figure placed in `visualisations/`.

| Model | Temp R² | Temp MAE (°C) | Temp RMSE (°C) | Hum R² | Hum MAE (%) | Hum RMSE (%) |
| --- | --- | --- | --- | --- | --- | --- |
| Persistence | 0.817 | 1.009 | 1.960 | 0.662 | 6.728 | 10.534 |
| ARIMA (per-city, AIC-selected) | 0.069 | 0.810 | 1.089 | -0.061 | 5.727 | 7.694 |
| LSTM | -0.344 | 3.616 | 5.308 | -0.368 | 17.411 | 21.217 |
| **Stacked Ensemble** | **0.933** | **0.801** | **1.184** | **0.786** | **6.336** | **8.386** |

* **Walk-forward validation (5 folds):** Temp R² = 0.935 ± 0.018, Hum R² = 0.898 ± 0.024
* **LOCO (all 543 cities):** median Temp R² = 0.816 (mean 0.685), median Hum R² = 0.834 (mean 0.712)
* **Improvement over persistence (stacked ensemble):** Temp MAE ↓ 20.5%, RMSE ↓ 39.6%; Hum MAE ↓ 5.8%, RMSE ↓ 20.4%

See `Methodology_Report.docx` Section 6 for full interpretation of each result, including why ARIMA and LSTM post near-zero or negative R² despite comparatively modest MAE (a target-variance effect, not a contradiction), and why humidity is intrinsically harder to forecast than temperature at several coastal locations.
